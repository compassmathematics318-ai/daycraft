## Material findings fixed and verified

- Editing legacy assessment metadata could re-create an occurrence previously excluded through its old exception list. The backend owner preserved exclusions unless the assessment is explicitly rescheduled.
- Old started/completed class blocks lacked new occurrence IDs. Initial legacy deduplication also suppressed additional manual meetings from the same activity. The independent regression reproduced the omission; the backend fix limits the fallback to the appropriate source, and the regression passes.
- A draggable event parent initially interfered with pointer resizing. The frontend disables parent dragging while the resize handle holds the pointer; real mouse resizing persists the intended end time.
- The inline seven-second success notice could disappear mid-gesture and move the calendar underneath the pointer, changing an intended 75-minute session into 145 minutes. The notice now renders outside document flow. The final browser regression holds the resize pointer for 7.5 seconds, verifies the calendar position remains unchanged through notice expiry, then verifies the exact snapped end time.
